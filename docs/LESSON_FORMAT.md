# فرمت درس‌ها (Lesson Format)

هر درس یک فایل JSON در `renderer/content/` است و در `content/index.json` ثبت می‌شود. تست‌های خودکار (`npm test`) همه‌ی فایل‌ها را اعتبارسنجی و رندر می‌کنند.

## ساختار فایل

```json
{
  "id": "u1-c-position",
  "unit": "u1",
  "title": "C Position – Right Hand",
  "titleFa": "موقعیت C – دست راست",
  "source": { "book": "…", "pages": [8, 9] },
  "steps": [
    { "type": "text", "id": "t1", "title": "…", "body": ["پاراگراف ۱", "پاراگراف ۲"], "highlight": ["C4", "D4"] },
    { "type": "exercise", "id": "e1", "title": "…", "instructions": "…",
      "hands": ["rh"], "tempo": 60, "score": { … } }
  ]
}
```

| فیلد | توضیح |
|---|---|
| `steps[].type` | `text` (درسنامه) یا `exercise` (تمرین). در فاز ۴ نوع `quiz` اضافه می‌شود. |
| `highlight` | نت‌هایی که روی کیبورد روشن می‌شوند (فقط `text`) |
| `hands` | دست‌هایی که **نوازنده** باید بنوازد. `rh` راست، `lh` چپ. در حالت «با ضرب» دست‌های دیگر را برنامه همراهی می‌کند |
| `tempo` | ضرب در دقیقه (۳۰ تا ۲۲۰) |
| `pass` | اختیاری: `{ "minAccuracy": 0.8 }` — حداقل دقت برای قبولی در حالت‌های تمرین (پیش‌فرض ۰٫۸) |

## بلوک `score`

```json
{
  "timeSignature": "4/4",
  "keySignature": "C",
  "ending": "final",
  "chordSymbols": { "0": "C" },
  "dynamics": { "0": "mf" },
  "staves": {
    "rh": ["E4/q:3 E4/q:3 F4/q:4 G4/q:5", "…"],
    "lh": ["r/w", "…"]
  }
}
```

- `staves.rh` و `staves.lh`: برای هر میزان یک رشته. اگر یک دست حذف شود، ایست کامل می‌گیرد. طول مجموع هر میزان باید دقیقاً با میزان‌نما برابر باشد (وگرنه اعتبارسنجی خطا می‌دهد).
- `chordSymbols` و `dynamics`: کلید = شماره میزان (از صفر).
- `keySignature`: `C G D A E B F Bb Eb Ab Am Em Bm Dm Gm Cm`
- `ending`: `final` (خط پایان)، `repeat` (علامت تکرار)، `none`

## دستور نوشتن هر رویداد (token)

```
PITCH/DURATION[.][:FINGERS][@lyric]
```

| نمونه | معنی |
|---|---|
| `C4/q` | دوی میانی، سیاه (quarter) |
| `E4/h:3` | می، سفید، انگشت ۳ |
| `D4/h.` | ر، سفید نقطه‌دار |
| `F#4/q`، `Bb3/q` | دیِز/بمل — **نت واقعی (صدای خروجی)** نوشته می‌شود؛ علامت روی حامل را رندرر با توجه به کلید و حافظه‌ی میزان خودش می‌گذارد |
| `C3+E3+G3/w:5-3-1` | آکورد: نت‌ها با `+`، انگشت‌ها از پایین به بالا با `-` |
| `r/q` | ایست سیاه |
| `G4/q:5@Play` | شعر زیر نت (`_` = فاصله) |

مدت‌ها: `w` گرد، `h` سفید، `q` سیاه، `e` چنگ. نقطه‌ی بعد از مدت یعنی ۱٫۵ برابر.

**قرارداد دست‌ها:** `rh` همیشه روی کلید سل و `lh` همیشه روی کلید فا نوشته می‌شود. دو در C میانی (C4) برای دست چپ با خط کمکی بالای حامل فا نمایش داده می‌شود.

## افزودن درس جدید

1. فایل JSON را در `renderer/content/<unit>/` بسازید.
2. مسیرش را به `renderer/content/index.json` اضافه کنید.
3. `npm test` را اجرا کنید؛ خطاهای میزان یا نت‌نویسی با نام گام و شماره میزان گزارش می‌شوند.
4. با `npm run dev:web` یا `npm start` نتیجه را ببینید.
