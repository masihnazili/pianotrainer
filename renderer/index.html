تنظیمات صدای پیانو

صدای سنتزشده همیشه در دسترس است؛ برای صدای طبیعی‌تر می‌توانی نمونه‌های WAV خودت را بارگذاری کنی.

میزبان Native هنوز اجرا نشده است.

برای صدای سمپل‌شده، فایل‌های WAV را انتخاب کن؛ نام هر فایل باید شمارهٔ MIDI (مثلاً 60.wav) یا نام نت (مثلاً C4.wav) باشد.

فایل‌ها فقط در همین اجرای برنامه نگه داشته می‌شوند؛ برای رعایت مجوز، بانک صدا را خودت انتخاب کن.
نکته: پلاگین‌های ساز (Instrument) را انتخاب کن؛ افکت‌های صوتی به‌تنهایی صدای پیانو تولید نمی‌کنند. برای استفاده از این بخش، ابتدا میزبان Native را بساز.
